# Повторная автоматическая проверка Stage1 Foundation

Шесть отчётов относятся к ревизии PR #71 `89c678a`. Проверенный GitHub merge-коммит `155a34c` имеет то же дерево исходников. Исторические решения о приёмке доступны в [снимке Stage1](../../acceptance/stage1-2026-11-08/README.md) и [отчётах capabilities](../../capabilities/stage1/).

В [HostOrbit CI](https://github.com/RoyMan810/HostOrbit/actions/runs/43947892644) прошли девять задач, включая Auth/RBAC/Audit, Docker, SSH и установку подписанной development-сборки на Ubuntu 24.04. Сборка содержит FastAPI 0.162.4 и annotated-doc 0.0.6. Прогон завершился с ошибкой на проверке прежних хешей отчётов Stage1. `ci-observations.json` фиксирует результаты задач и шагов.

`source-manifest.json` связывает проверенные исходники, установщик и зависимости с ревизией. Проверены SHA-256 ZIP-артефакта, подпись Ed25519 манифеста, хеш SBOM и соответствие SHA-256 двух обновлённых wheel-файлов в SBOM хешам в lock-файле репозитория. Сохранены манифест, подпись, SBOM и открытый тестовый ключ. Отчёты охватывают Foundation. Stage2, независимый DR и нагрузочная приёмка проверяются отдельно.
