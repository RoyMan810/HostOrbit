# Повторная автоматическая проверка Stage1 Foundation

Шесть отчётов относятся к ревизии PR #76 `b706cbb`. Проверенный GitHub merge-коммит `466c83d` имеет то же дерево исходников. Исторические решения о приёмке доступны в [снимке Stage1](../../acceptance/stage1-2026-11-08/README.md) и [отчётах capabilities](../../capabilities/stage1/).

В [HostOrbit CI](https://github.com/RoyMan810/HostOrbit/actions/runs/43954965908) прошли девять задач, включая Auth/RBAC/Audit, SSH и установку подписанной development-сборки на Ubuntu 24.04. Нативная проверка обнаружения Docker подтвердила mounts и различие между обычной сетью и режимом none в SSH probe v6. Прогон завершился с ошибкой на проверке прежних хешей отчётов Stage1. `ci-observations.json` фиксирует результаты задач и шагов.

`source-manifest.json` связывает проверенные исходники, установщик и зависимости с ревизией. Проверены SHA-256 ZIP-артефакта, подпись Ed25519 манифеста и хеш SBOM. Сохранены манифест, подпись, SBOM и открытый тестовый ключ. Отчёты охватывают Foundation. Stage2, независимый DR и нагрузочная приёмка проверяются отдельно.
