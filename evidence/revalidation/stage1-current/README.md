# Повторная автоматическая проверка Stage1 Foundation

Шесть отчётов относятся к проверочной ревизии PR #64 `665485dfa91014b20e7c490461379e92e25ae7f6`. Её дерево совпадает с деревом коммита `3783613350f6010bcdda02ba2cbf7068d3967711`. Исторические отчёты и решения о приёмке доступны в [снимке Stage1](../../acceptance/stage1-2026-11-08/README.md) и [отчётах capabilities](../../capabilities/stage1/). Gate проверяет хеши файлов, указанных в текущих отчётах.

`source-manifest.json` связывает проверенные исходники, deploy-конфигурацию, тесты и зависимости с ревизией. Подписанный development bundle собран и установлен на временной Ubuntu 24.04 в GitHub Actions с Python 3.15.2. Проверены SHA-256 артефакта, подпись Ed25519 manifest и хеш SBOM в manifest. Сохранены manifest, подпись, SBOM и открытый тестовый ключ. SBOM охватывает Python-пакеты, базовый образ и age.

В [прогоне HostOrbit CI для PR #64](https://github.com/RoyMan810/HostOrbit/actions/runs/42982633115) девять задач прошли, включая нативные проверки Docker, SSH и установки. Stage0 прошёл. Общий результат прогона — `failure`, поскольку Stage1 проверял предыдущие отчёты с устаревшими хешами. `ci-observations.json` фиксирует результаты задач и шагов этого прогона.

Объём этих отчётов ограничен Foundation. Stage2, выпуск MVP, независимое DR и нагрузочная приёмка проверяются отдельно.
