# Повторная автоматическая проверка Stage1 Foundation

Шесть отчётов относятся к ревизии PR #90 `bb081c2`. Проверенный GitHub merge-коммит `466593b` имеет то же дерево исходников. Исторические решения доступны в [записи о приёмке Stage1](../../acceptance/stage1-2026-11-08/decision.json) и [отчётах capabilities](../../capabilities/stage1/).

В [HostOrbit CI](https://github.com/RoyMan810/HostOrbit/actions/runs/44167693453) прошли девять задач, включая Auth/RBAC/Audit, SSH и установку подписанной development-сборки со схемой 3 на Ubuntu 24.04. Подписанный пакет прошёл тесты миграционной репетиции и восстановления. Проверка прежних хешей Stage1 завершила исходный прогон с кодом 2. `ci-observations.json` фиксирует результаты задач и шагов.

`source-manifest.json` связывает проверенные исходники, установщик и зависимости с ревизией. Проверены SHA-256 ZIP-артефакта, подпись Ed25519 манифеста и хеш SBOM. Сохранены манифест, подпись, SBOM и открытый тестовый ключ. Отчёты охватывают Foundation. Stage2, независимый DR и нагрузочная приёмка проверяются отдельно.
