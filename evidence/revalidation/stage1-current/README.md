# Повторная автоматическая проверка Stage1 Foundation

Шесть отчётов относятся к ревизии PR #94 `6031ede`. Проверенный GitHub merge-коммит `66a1358` имеет то же дерево исходников. Исторические решения доступны в [записи о приёмке Stage1](../../acceptance/stage1-2026-11-08/decision.json) и [отчётах capabilities](../../capabilities/stage1/).

В [HostOrbit CI](https://github.com/RoyMan810/HostOrbit/actions/runs/44256699605) прошли восемь задач, включая Auth/RBAC/Audit, ограниченный SSH с ротацией ключа и подписанную установку со схемой 3. На установленном пакете прошли миграционные репетиции, восстановление и публикация через OpenSSH SFTP. Проверка Stage1 по реестру v2.4 завершилась кодом 2 из-за прежних хешей. `ci-observations.json` фиксирует результаты исходного прогона.

`source-manifest.json` связывает проверенные исходники, установщик и зависимости с ревизией. Проверены SHA-256 ZIP-артефакта, подпись Ed25519 манифеста и хеш SBOM. Сохранены манифест, подпись, SBOM и открытый тестовый ключ. Отчёты охватывают Foundation. Stage2, независимый DR и нагрузочная приёмка проверяются отдельно.
