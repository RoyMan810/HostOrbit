# Действующие проверки Stage1 Foundation

Шесть отчётов связывают проверенные возможности Foundation с исходниками и подписанной сборкой. Ревизия и хеши файлов указаны в [манифесте исходников](source-manifest.json). [Результаты GitHub Actions](ci-observations.json) содержат ссылку на прогон, статусы задач и шагов.

Проверка использует подпись Ed25519 манифеста тестовой сборки и сверяет SHA-256 её SBOM. При изменении закреплённых файлов требуется новый прогон и повторная проверка артефакта. Допуски Stage2, независимого аварийного восстановления и нагрузки определяются отдельно в [реестре](../../../docs/spec/HostOrbit_Requirements_Registry_v2.4.json).
