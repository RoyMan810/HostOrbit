# Материалы ревью Stage 0

Пакет связывает лабораторные наблюдения с кодом и прогонами CI. Его 15 отчётов имеют `outcome=NOT_RUN`, `review_status=PENDING` и пустое поле рецензента. Эти записи служат черновиками для приёмки. Копирование их в каталог принятых свидетельств не откроет gate.

`source-manifest.json` перечисляет SHA-256 каждого файла коммита `68685ba7fc10c34f6bb16a1cac0910adc082e6a2`. Его дерево совпадает с проверенной веткой PR #23. `build_digest` относится к исходникам лаборатории. `sbom.cdx.json` описывает закреплённые компоненты лаборатории, подтверждённые CI, с явно ограниченной областью состава.

`ci-observations.json` содержит ссылки на пять успешных jobs, SHA-256 полных декодированных журналов GitHub и выбранные строки наблюдений. Прогон [42340021014](https://github.com/RoyMan810/HostOrbit/actions/runs/42340021014) включает 55 unit-тестов, четыре SFTP-теста, Broker и ограниченный SSH. Прогон [42340021023](https://github.com/RoyMan810/HostOrbit/actions/runs/42340021023) объединяет потерю старой VM, перенос Vault и ожидающий эффект Docker.

В `reports.json` сохранены исходное состояние, сценарий, fault injection, наблюдение, привязки к manifest/SBOM и дайджест каждого отчёта. Дайджест вычисляется функцией `stage0.requirements.evidence_digest` из всех полей отчёта, кроме самого дайджеста. Изменение заключения, времени или рецензента требует нового дайджеста.

`baseline-amendment.json` фиксирует единственное изменение AC-28. `baseline-check.json` содержит результат сверки оригинального MD и обновлённого JSON, а также SHA-256 исполняемого проверяющего модуля. Новые тесты checker и замены БД приложения относятся к следующей проверяемой ревизии исходников. Они отмечены отдельно от 55 тестов исторического прогона.

При ревью нужно сопоставить каждое утверждение с журналом и кодом, оценить ограничения и оформить заключение в отдельном принятом отчёте с фактическим временем и рецензентом. После этого обновляются только соответствующие статусы canonical registry и повторяется `stage0.requirements --gate Stage0`. Наличие manifest, SBOM или зелёного CI само по себе не меняет статус приёмки.

Две гостевые Ubuntu VM имеют разные writable-диски. SFTP, управляемая служба и Docker находятся на их общем гипервизоре. Независимого оператора воспроизводит стенд. Для Backend внутри TCB явно сохранено наблюдение злоупотребления подделанным approval в заранее разрешённом scope. Пакет не удостоверяет production deploy, независимый физический DR или полноту окружения выпуска MVP.
