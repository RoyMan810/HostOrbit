# Первая рабочая версия VPN-Orbit

Один владелец управляет своими VPS из браузера. Первый профиль управляемого хоста — Ubuntu Server 24.04 LTS amd64, OpenSSH по IPv4, systemd и Docker Compose v2. Для HTTPS используем Nginx. DNS настраивается вручную.

Текущие статусы и критерии завершения ведутся в [README](../README.md#прогресс-первой-версии).

## Следующие задачи

1. Подключение чистой VPS из браузера. Проверить SSH-отпечаток, настроить ограниченный сервисный доступ и подготовить ОС.
2. Управление firewall с проверкой нового SSH-соединения и откатом при потере доступа.
3. Развёртывание Remnawave Panel и Node с Nginx/TLS и настройками в веб-интерфейсе. Первичная регистрация Node выполняется в Remnawave Panel.
4. Развёртывание Bedolaga Bot и Cabinet с HTTPS webhook и проксированием API кабинета.

Первая версия должна поддерживать подключение известных Compose-профилей с явным подтверждением владельца, проверять дрейф перед изменениями и сохранять данные, внешние тома и общие ресурсы при удалении. Неопределённый результат операции требует сверки перед новыми изменениями. Для пользовательских ошибок сохраняются этап, результат и идентификатор диагностики.

Выпуск проверяется локальными тестами и сквозными сценариями на отдельном стенде. Резервное копирование, перенос старой базы, обновление приложений и расширенный интерфейс аудита отложены.
