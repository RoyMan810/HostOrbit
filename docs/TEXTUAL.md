# Современный интерфейс K-VPN на Textual

Интерфейс на Python-библиотеке [Textual](https://textual.textualize.io/) удобен для SSH: полноценный экран терминала с боковым меню, статусами компонентов, журналом выполнения, формами ввода и отдельным подтверждением действий. **Это локальный терминальный интерфейс, а не веб-панель** — открывать дополнительные сетевые порты не нужно.

## Как установить и открыть

1. Подключитесь к серверу по SSH **с интерактивным терминалом**. Для первоначальной настройки нового VPS используйте консоль провайдера как резервный доступ.
2. Скачайте установщик на сервер (без выполнения `curl | bash`):

   ```bash
   curl -fL --proto '=https' --tlsv1.2 -o kvpn-install.sh \
     https://raw.githubusercontent.com/RoyMan810/kvpn-node-deployer/main/kvpn-install.sh
   bash kvpn-install.sh help
   ```

3. Откройте панель:

   ```bash
   sudo bash kvpn-install.sh tui
   ```

4. При первом запуске программа предложит установить `python3-venv` (при необходимости) и `textual==8.2.8` в `/opt/kvpn-node-deployer-textual`. Введите **`yes`**, только если доверяете исходникам и хотите поставить интерфейс. Системный Python не модифицируется.

**Для использования напрямую из клонированного репозитория:** `sudo bash install.sh tui`. Нужны Ubuntu 24.04/26.04/26.10 или Debian 12/13, systemd, APT, Python 3, доступный TTY. Textual требует терминал с поддержкой современных escape-последовательностей. На маленьком экране увеличьте окно SSH.

## Навигация

- `↑` и `↓` — перемещение по боковому меню; `Enter` — выделить раздел; **«Выполнить»** — начать выбранную команду.
- Во всплывающем окне: `Enter` — продолжить; `Esc` — отмена. Для действий с изменениями сначала показывается отдельное предупреждение.
- `R` или `F5` — обновить состояния; `Q` или **«Выход»** — закрыть интерфейс. Во время выполнения скрипта выход блокируется, чтобы не оборвать операцию случайно.
- В нижнем журнале виден вывод Bash, сообщения об ошибках и завершение команды. Секреты из формы не отображаются и не записываются в лог интерфейса.

## Какую функцию выбрать

- **Проверка VPS** — сначала запустите на любом сервере. Ничего не изменяет.
- **Состояние сервисов / мониторинга / публичные SSH-ключи** — безопасный просмотр состояния и разрешённых к публикации ключей.
- **Установить Docker / Настроить UFW / Remnawave Node / Полная установка** — **только на новом VPS**. Возьмите compose-файл ноды в Remnawave Panel заранее; для `node` нужен защищённый UFW. [Инструкция](NEW-VPS.md).
- **Добавить RU-источник** — для управляемой Foreign-ноды добавить один IPv4/CIDR. Не удаляет существующие правила UFW.
- **HTTPS для REALITY / резервное копирование** — отдельные сервисы; см. [Инструкция](SERVICES.md).
- **Мониторинг на панели** — поставить приёмник и указать Telegram chat_id/topic_id/token. **RU-проверка** и **Foreign-проверка** — создать агента с уникальным ID. **Зарегистрировать агента** — вставить полный публичный ключ `ssh-ed25519 …` и отдельный исходящий IP агента. После регистрации включите systemd-таймер **на агенте** по инструкции. [Полный порядок](MONITORING.md).
- **Тест Telegram** — посылает реальное тестовое сообщение; **Диагностика** — записывает root-only файл, его нужно проверить перед передачей другим лицам.

## Дополнительно: изоляция и совместимость

Textual **не заменяет** серверный Bash-движок. Без Python/UI продолжат работать прямые команды `sudo bash kvpn-install.sh monitor status` и другие из [README](../README.md). Интерфейс не перезаписывает работающую ноду/панель и не управляет настройками VPN в Remnawave Panel.

Если Textual недоступен (нет интернет-доступа для pip, нет Python/TTY или установка отклонена), скрипт предлагает старое **whiptail**-меню. Чтобы гарантированно пропустить обе библиотеки, используйте:

```bash
sudo bash kvpn-install.sh text-menu
```

Для старого полноэкранного меню:

```bash
sudo env KVPN_FORCE_LEGACY_TUI=1 bash kvpn-install.sh menu
```

Повторная установка Textual не выполняется, если библиотека уже доступна в подходящем venv. Окружение хранится в `/opt/kvpn-node-deployer-textual`; это зависимость интерфейса, **не VPN и не мониторинга**. Не удаляйте его, пока используете TUI.

## Если что-то пошло не так

- При ошибке `No module named textual` проверьте отдельное окружение `/opt/kvpn-node-deployer-textual/bin/python`; у системы может не быть сети для установки PyPI.
- При ошибке установки `venv/ensurepip` проверьте пакет `python3-venv` из APT.
- При ошибках ввода проверьте, что используете именно интерактивный SSH-терминал, а не `cron` или перенаправленный stdin.
- При отмене скрипта проверяйте реальное состояние systemd/UFW/Docker перед повторением: **автоматического отката нет**.
- При повреждённом интерфейсе всегда можно пользоваться [командами без TUI](../README.md#справочник-команд-без-tui).
