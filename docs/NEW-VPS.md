# Установка новой ноды: Docker, UFW и Remnawave Node

Это руководство — **для нового Ubuntu/Debian VPS без действующего Remnawave Node**. Для управления уже работающей панелью или миграции существующей ноды мастер не предназначен.

## 1. Подготовить сервер и Remnawave Panel

Вам понадобятся:

1. **Консоль провайдера VPS** на случай ошибки UFW или потери SSH.
2. Публичный **IPv4 Remnawave Panel** — именно оттуда Node API принимает управляющие подключения.
3. Созданная в Remnawave Panel новая нода: панель должна выдать **`docker-compose.yml`** с секретом. Сохраните точный файл на VPS, например `/root/new-remnanode-compose.yml`. Не копируйте секрет в чат или issues.
4. **Порт Node API** из compose-файла (`NODE_PORT` или `APP_PORT`, например `2222`). Не путайте его с входящим портом Xray.
5. **Входящий TCP-порт Xray:** например `443` на RU или `8443` на Foreign; фактический порт позднее должен совпадать с Config Profile в панели.
6. **Текущий SSH-порт** сервера (например, `22`). Если активен UFW, мастер **не расширяет** существующие SSH-правила.

Обозначения: RU — входная нода с доступом клиентов; Foreign — зарубежная выходная нода, входящий TCP-порт которой обычно доступен **только с разрешённых RU-адресов**. Это не универсальная схема и не автоматическая маршрутизация: реальную цепочку задают в Remnawave/Xray.

Для файла compose используйте `chmod 600 /root/new-remnanode-compose.yml` и убедитесь, что путь **абсолютный**, файл не символическая ссылка. Не используйте compose с другого проекта.

## 2. Загрузить установщик

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl
curl -fL --proto '=https' --tlsv1.2 -o kvpn-install.sh \
  https://raw.githubusercontent.com/RoyMan810/kvpn-node-deployer/main/kvpn-install.sh
bash kvpn-install.sh preflight
sudo bash kvpn-install.sh
```

Меню: стрелки — пункт; `Enter` — выбор; `Esc` — назад. Установить `whiptail` предложит сам скрипт. На терминале меньше 65×20 символов используется текстовое меню. Сохраните подключение через консоль провайдера до проверки SSH после UFW.

## 3А. Самый простой путь — «Полная установка ноды»

Выберите `Полная установка ноды` (CLI: `sudo bash kvpn-install.sh wizard`). Мастер последовательно спросит:

- **Роль:** `ru` или `foreign`.
- **Remnawave Panel public IPv4:** конкретный адрес панели, например `192.0.2.10` (*адрес документации, замените своим*).
- **Node API port:** как в compose (`2222` — пример). Он открывается по UFW только для адреса панели.
- **Xray TCP inbound:** выбранный фактический TCP-порт профиля Xray (например, RU `443`, Foreign `8443`).
- **Allowed source:** RU обычно `0.0.0.0/0` (публичный доступ клиентов); Foreign — конкретный RU IPv4/CIDR или список через запятую **без пробелов** (`192.0.2.11,198.51.100.22`). Foreign не принимает `0.0.0.0/0`.
- **Current SSH port:** действующий порт SSH, не угадывайте; на новом неактивном UFW мастер проверит наличие TCP-listener и порт текущей SSH-сессии.
- **ACME port 80:** `yes` только если планируется локальный HTTPS для REALITY через Let's Encrypt HTTP-01.
- **Compose path:** например `/root/new-remnanode-compose.yml`.

Перед выполнением подтвердите действия. Установщик проверит compose (строго один сервис `remnanode`, официальный образ, `network_mode: host`, совпадение Node API port и наличие секрета), установит зависимости, Docker, **загрузит образ**, затем настроит UFW и запустит контейнер.

После запуска предложит по желанию резервное копирование, HTTPS и мониторинг. Не соглашайтесь на мониторинг, пока не подготовлена отдельная мониторинговая панель.

## 3Б. Раздельная установка нужных компонентов

На **чистом VPS** можно делать поэтапно:

```bash
sudo bash kvpn-install.sh firewall   # сначала закрытый Node API и VPN-порт
sudo bash kvpn-install.sh docker     # при необходимости Docker
sudo bash kvpn-install.sh node       # только Node, UFW больше не меняется
```

`firewall` устанавливает необходимые пакеты, добавляет правила и **может включить UFW**. Если UFW уже активен, его существующие SSH-правила остаются как есть. `node` проверяет, что UFW активен, входящая политика — deny, Node API **не открыт всем**, а от адреса панели есть разрешающее правило. Если защита отсутствует, установка будет остановлена.

Управляющий порт и VPN-порт не должны совпадать с SSH-портом. Если Docker уже установлен **без Compose plugin**, установщик откажется заменять компоненты автоматически: исправьте имеющуюся конфигурацию вручную.

## 4. Как проверить результат

```bash
sudo bash kvpn-install.sh status
sudo ufw status numbered
cd /opt/remnanode && sudo docker compose ps
sudo ss -lnt | grep -E ':(2222|443|8443) '
```

`/opt/remnanode/docker-compose.yml` — сохранённый файл из панели; `/etc/kvpn-node-deployer/node.env` — настройки роли, портов и разрешённых IP; оба файла root-only. Не копируйте их в публичные отчёты.

**Важно:** TCP-порт Xray **может ещё не слушать**, пока в Remnawave Panel не задан корректный Config Profile. Успех `docker compose ps` означает работающий контейнер, но **не** рабочую VPN-цепочку. Проверьте подключение реальным клиентом.

## 5. Добавление ещё одной RU-ноды

Только на Foreign VPS, ранее установленном этим инструментом:

```bash
sudo bash kvpn-install.sh firewall-add-ru
```

Введите **публичный IPv4 или CIDR** нового RU-источника и подтвердите добавление одного UFW-правила. Операция не меняет Docker, Node и Xray; настройки соответствующего маршрута в Remnawave Panel должны быть обновлены отдельно. На чужих или вручную настроенных нодах скрипт откажет в операции.

## Важные замечания

- Используется **TCP**-вариант правил; конфигурации UDP, IPv6 или специфичных протоколов требуют отдельной проверки.
- Docker с опубликованными портами (`ports:`) в **других контейнерах** может обходить UFW; на рабочем хосте учитывайте все Docker-правила. Установщик проверяет только Compose одной Remnawave Node c `network_mode: host`.
- При неуспешной загрузке образа файлы ноды и UFW не изменяются, но Docker/пакеты могли уже установиться. При ошибке **после** создания файлов не запускайте полный мастер повторно — изучите `docker compose logs` и состояние контейнера.
- **Remnawave Panel и Xray-профили не устанавливаются этим инструментом.**
