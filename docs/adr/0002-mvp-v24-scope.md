# ADR-0002 · Объём MVP v2.4

Решение принято 17.11.2026. Активные документы — [ТЗ v2.4](../spec/HostOrbit_Technical_Spec_v2.4.md) и [реестр v2.4](../spec/HostOrbit_Requirements_Registry_v2.4.json).

Первый полный сценарий ограничен ручным управлением одним импортированным тестовым Docker Compose-контейнером. Публикация Nginx, планировщик, отдельные веб-мастера и дополнительные центры отложены. Для AC-28 определён узкий класс перезапуска и его отрицательные проверки. Проектное правило требует реализации и приёмки.

Принятые свидетельства Stage0 и Foundation сохраняют свои ревизии. Статусы изменённых критериев остаются `NOT_RUN`. Установка, обновление, резервное копирование и восстановление продолжают использовать отдельные проверки и требования безопасности.
