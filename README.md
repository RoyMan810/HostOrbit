# K-VPN Node Deployer

Установщик **новых серверов K-VPN** с Remnawave Node и Xray.

Поддерживает два варианта:
- **RU** — входная нода в России.
- **Foreign** — выходная нода за пределами России.

Помогает установить Docker, настроить сетевой доступ, резервные копии, а при необходимости — HTTPS для REALITY и мониторинг.

> **Важно:** установщик предназначен для **нового, чистого VPS**. На работающих нодах K-VPN его запускать не нужно. Полное развёртывание на реальном сервере пока не испытано — первую установку делайте на тестовом VPS.

## Быстрая установка

**1. Создайте новую ноду в Remnawave Panel** и сохраните выданный панелью файл `docker-compose.yml` на новом VPS, например в `/root/new-remnanode-compose.yml`. **Не публикуйте его** — там находятся секреты.

**2. Скачайте установщик** на новом сервере (Ubuntu/Debian):

```bash
curl -fL --proto '=https' --tlsv1.2 \
  -o kvpn-install.sh \
  https://raw.githubusercontent.com/RoyMan810/kvpn-node-deployer/main/kvpn-install.sh
```

**3. Проверьте сервер** без изменений:

```bash
bash kvpn-install.sh preflight
```

**4. Ознакомьтесь со скриптом и запустите мастер:**

```bash
sudo bash kvpn-install.sh wizard
```

Мастер попросит выбрать **RU / Foreign**, указать адрес панели, порты и путь к `docker-compose.yml`. Дополнительные компоненты можно выбрать отдельно.

**5. Завершите настройку в Remnawave Panel:** привяжите нужный **Config Profile**, настройте маршруты и REALITY, затем проверьте VPN. Установщик не настраивает эти параметры автоматически.

## Дополнительные возможности

- **UFW** — ограничение входящих подключений.
- **HTTPS-сайт для REALITY** — локально на `127.0.0.1:9444`.
- **Резервные копии** — ежедневно, хранение 14 дней.
- **Мониторинг** — проверка доступности ноды и уведомления в Telegram через отдельную панель мониторинга.

> На действующей Host-Panel-NL уже установлен мониторинг. Новый комплект **не подключается к нему автоматически**. Не запускайте `monitor panel` на текущей панели.

## Проверка после установки

```bash
sudo bash kvpn-install.sh status
sudo bash kvpn-install.sh diagnostics
```

Проверка контейнера:

```bash
cd /opt/remnanode && sudo docker compose ps
```

## Безопасность

- Не используйте мастер установки для обновления работающих нод.
- Перед запуском от `root` изучите скрипт и сохраните доступ к консоли VPS на случай ошибки UFW.
- Не размещайте в GitHub токены Telegram, ключи SSH/REALITY, `docker-compose.yml` панели и резервные копии.
- Для повторяемой установки лучше скачивать проверенную версию по конкретному коммиту и сверять SHA-256.

**Итого:** создать ноду в панели → скачать установщик → `preflight` → `wizard` → завершить настройки в Remnawave Panel.

Дополнительно: [документация Remnawave Node](https://docs.rw/install/remnawave-node/) · [безопасность проекта](SECURITY.md).
