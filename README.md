# HostOrbit

Панель для управления VPS и развёртывания Remnawave Panel, Remnawave Node, Bedolaga Bot и Cabinet.

## Текущее состояние

- Доступны вход владельца, наблюдение заранее подготовленной VPS, просмотр зарегистрированных контейнеров и стендовый перезапуск одной разрешённой цели.
- В работе упрощение подключения VPS, исполнения операций и установки контроллера.
- Запланированы подготовка VPS из браузера, управление firewall, установка и настройка VPN-компонентов, подключение существующих установок и безопасное удаление.

## Запуск development-сборки

На чистой Ubuntu Server 24.04 или 26.04 amd64:

```sh
git clone https://github.com/RoyMan810/HostOrbit.git
sudo ./HostOrbit/install
```

Установщик покажет локальный HTTPS URL, команду SSH-туннеля и путь к сертификату. Для публичного HTTPS используйте `--public-domain` с готовым сертификатом Certbot. [Инструкция установки](docs/stage1-installation.md) · [Подключение VPS и диагностика](docs/stage2-inventory.md)
