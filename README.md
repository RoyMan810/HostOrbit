# HostOrbit

HostOrbit — панель для управления Linux-серверами на собственной инфраструктуре. Контроллер опрашивает VPS по SSH и показывает в веб-интерфейсе состояние хостов, контейнеров Docker Compose и их опубликованных портов.

**Stage0, Stage1 и Stage2 приняты.** Владелец принял AC-28 по итогам локального прогона. Controller, управляемая Ubuntu VM и SFTP работали на одном физическом ПК. [Протокол приёмки](evidence/acceptance/stage2-ac-28/decision.md) Доступна подписанная сборка для разработки под Ubuntu 24.04 и новее (amd64). Приёмка для эксплуатации ещё предстоит.

## Быстрый запуск

На чистой Ubuntu Server 24.04 или 26.04 amd64:

```sh
git clone https://github.com/RoyMan810/HostOrbit.git
sudo ./HostOrbit/install
```

Установщик соберёт development-версию и покажет URL, команду SSH-туннеля и путь к сертификату для браузера. [Установка и подключение первой VPS](docs/stage1-installation.md#установка-одной-командой)

## Выполнено

- **Основа контроллера.** Подписанная установка, локальное создание владельца (Owner), вход, разграничение доступа и журнал аудита. [Проверки Stage1](evidence/revalidation/stage1-current/README.md)
- **Инвентарь VPS.** Владелец подключает заранее разрешённую VPS по независимо проверенному отпечатку SSH-ключа. Для зарегистрированного хоста доступны SSH-проверка, время последнего наблюдения, состояние импортированных контейнеров и опубликованные порты IPv4/IPv6. [Инвентарь и диагностика](docs/stage2-inventory.md)
- **Стендовый перезапуск.** Владелец может создать план изменения (Change Plan), проверить цель, подтвердить ревизию и отправить перезапуск в очередь. Ход и результат видны в истории операции (Timeline). Требуются явно настроенная тестовая цель и отдельный SSH-ключ. [Веб-интерфейс](web/README.md)
- **Аудит.** Доступны история SSH-заданий, проверка целостности, экспорт с предпросмотром и сохранённая ревизия плана с результатом. После потери ответа владелец может сверить подтверждения перезапуска по журналам контроллера.
- **Восстановление Docker-тома.** Восстановление в новый пустой том и отказ для занятого тома прошли лабораторную приёмку. [AC-B05 · PASS](evidence/tests/ac-b05.json)
- **Архивы и ключи.** Остановленный Docker-том можно сохранить в подписанный зашифрованный архив. Удаление локальной копии ControllerBackup требует проверки внешней копии и зависимостей. Доступны ротация и отзыв ключей наблюдения, перезапуска и SFTP. [Архивы](docs/stage1-rescue.md) · [Хранение](docs/stage1-sftp-publication.md) · [Ключи](docs/stage1-runtime.md)

## Предстоит до выпуска MVP

- Реализовать подписанные A/B-обновления контроллера и безопасную миграцию БД.
- Принять правила хранения на независимом хранилище.
- Подтвердить ручной допуск операций после восстановления и пройти независимую проверку аварийного восстановления с замером RPO/RTO.
- Пройти полную приёмку Stage3, включая безопасность, доступность интерфейса и нагрузку на контроллере с 1 vCPU, 2 ГиБ ОЗУ и 40 ГиБ SSD.

В MVP владелец меняет DNS вручную. Для Nginx и Caddy предусмотрено наблюдение. Изменения Firewall и SSH через панель выходят за рамки MVP.
