# HostOrbit

Self-hosted система управления Linux-серверами по [ТЗ v2.4](docs/spec/HostOrbit_Technical_Spec_v2.4.md). Прикладной Controller включает локальное создание Owner, Auth/RBAC, SQLite с Audit/Outbox, изолированные Worker/Broker, SSH observation, резервное копирование и восстановление.

## Текущее состояние

**До production проект не готов.** [Stage0 принят](evidence/acceptance/stage0-2026-11-07/README.md) по 15 обязательным проверкам прототипов. [Stage1 Foundation был принят](evidence/acceptance/stage1-2026-11-08/README.md) на исторической ревизии. [Повторная проверка Foundation](evidence/revalidation/stage1-current/README.md) содержит шесть отчётов для ревизии `89c678a` с обновлёнными Python-зависимостями. На `main` после слияния PR #68 [HostOrbit CI](https://github.com/RoyMan810/HostOrbit/actions/runs/43026673122) прошёл все 10 задач на `a3dddff`, включая gates Stage0 и Stage1, нативные проверки Docker, SSH и подписанной установки. [Отдельный сценарий потери исходной VM](https://github.com/RoyMan810/HostOrbit/actions/runs/42804027706) проверен на ревизии `722d486`. Stage2, независимый DR и полная приёмка MVP остаются открытыми.

Доступна подписанная **development**-установка на Ubuntu 24.04 и новее, amd64; native-установка проверена на 24.04 и 26.04. Единственный включённый remote adapter — read-only `host.probe`. Production mutations, A/B updates, live migration и независимая DR-приёмка остаются открытыми.

## Задачи до production

**Выполнено** — реализовано и проверено в указанном объёме. **В процессе** — есть реализация или репетиция, остаются работы или приёмка. **Предстоит** — обязательная работа ещё открыта.

[Реестр v2.4](docs/spec/HostOrbit_Requirements_Registry_v2.4.json) определяет критерии. Первый сквозной сценарий — одна Ubuntu VPS, один импортированный тестовый Docker Compose-контейнер и ручной перезапуск через Change Plan. Управление Nginx, планировщик, отдельные центры хранения и уведомлений, расширенные веб-мастера и Support Bundle отложены. Nginx и Caddy остаются в объёме наблюдения.

```sh
python3.15 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt -r requirements-quality.txt
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/ruff check .
.venv/bin/python tools/check_repository.py
.venv/bin/python -m unittest discover -s tests_tools -v
```
