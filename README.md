# HostOrbit

HostOrbit — панель для управления Linux-серверами на собственной инфраструктуре. Контроллер опрашивает VPS по SSH и показывает в веб-интерфейсе состояние хостов, контейнеров Docker Compose и их опубликованных портов.

**Сейчас проект готовится к стендовым испытаниям.** Stage0 и Stage1 приняты. Для завершения Stage2 остался AC-28. Доступна подписанная сборка для разработки под Ubuntu 24.04 и новее (amd64). Приёмка для эксплуатации ещё предстоит.

## Выполнено

- **Основа контроллера.** Подписанная установка, локальное создание владельца (Owner), вход, разграничение доступа и журнал аудита. [Проверки Stage1](evidence/revalidation/stage1-current/README.md)
- **Инвентарь VPS.** Для зарегистрированного хоста доступны SSH-проверка, время последнего наблюдения, состояние импортированных контейнеров и опубликованные порты IPv4/IPv6. [Инвентарь и диагностика](docs/stage2-inventory.md)
- **Стендовый перезапуск.** Владелец может создать план изменения (Change Plan), проверить цель, подтвердить ревизию и отправить перезапуск в очередь. Ход и результат видны в истории операции (Timeline). Требуются явно настроенная тестовая цель и отдельный SSH-ключ. [Веб-интерфейс](web/README.md)
- **Аудит.** Доступны история SSH-заданий, проверка целостности журнала и экспорт выбранных событий с предпросмотром.
- **Восстановление Docker-тома.** Восстановление в новый пустой том и отказ для занятого тома прошли лабораторную приёмку. [AC-B05 · PASS](evidence/tests/ac-b05.json)

## В процессе

| Задача | Что осталось |
|---|---|
| **AC-28 · ближайшая проверка** | На чистом контроллере и отдельной Ubuntu VPS перезапустить один импортированный тестовый контейнер. Сверить результат с Docker и журналом, проверить отказы и потерю связи. Отдельно подтвердить публикацию и проверку копии контроллера (ControllerBackup) на защищённом SFTP-хранилище. |
| Подключение VPS и доступ | Завершить форму подключения с подтверждением отпечатка ключа SSH-сервера, отображение зависимостей и приёмку прав на конкретную VPS. |
| Операции и аудит | Завершить обработку прерванных заданий, сверку неопределённого результата и просмотр полного плана в аудите. |
| Архивы, секреты и перенос | Завершить создание архивов ресурсов, ротацию и отзыв секретов, штатный перенос контроллера. |
| Интерфейс и справка | Доработать диагностику в карточке VPS, настройки, управление с клавиатуры и инструкции на русском и английском. |

## Предстоит до выпуска MVP

- Реализовать подписанные A/B-обновления контроллера и безопасную миграцию БД.
- Завершить учёт и сроки хранения архивов с защитой последней пригодной внешней копии.
- Подтвердить ручной допуск операций после восстановления и пройти независимую проверку аварийного восстановления с замером RPO/RTO.
- Пройти полную приёмку Stage3, включая безопасность, доступность интерфейса и нагрузку на контроллере с 1 vCPU, 2 ГиБ ОЗУ и 40 ГиБ SSD.

В MVP владелец меняет DNS вручную. Для Nginx и Caddy предусмотрено наблюдение. Изменения Firewall и SSH через панель выходят за рамки MVP.
