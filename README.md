# HostOrbit

Панель для управления VPS из браузера. Цель первой версии — подключение и подготовка сервера, развёртывание и обслуживание Remnawave Panel, Remnawave Node, Bedolaga Bot и Cabinet.

## Что уже работает

- **Контроллер и доступ.** Установка development-сборки, локальное создание учётной записи владельца, вход через HTTPS. Встроенный Nginx поддерживает локальный доступ через SSH-туннель и публичный домен с готовым сертификатом Certbot.
- **Инвентарь VPS.** Подключение заранее внесённых SSH-целей с проверкой отпечатка, проверка доступности и просмотр результатов наблюдения. Для зарегистрированных Docker-контейнеров видны состояние и опубликованные порты.
- **Операции на стенде.** Предпросмотр, подтверждение и перезапуск явно разрешённого тестового контейнера. В интерфейсе доступны результат операции, хронология и журнал аудита.

[Инвентарь и ограничения](docs/stage2-inventory.md) · [Руководство по веб-интерфейсу](web/README.md)

## Прогресс первой версии

**Ближайший этап** — общая очередь для наблюдений и изменений. После неё — подключение и подготовка чистой VPS из браузера.

| Задача | Статус | Как проверить завершение |
| --- | --- | --- |
| Убрать устаревшие требования и материалы приёмки | Готово | В репозитории опубликован действующий [план первой версии](docs/first-release.md). |
| Установка контроллера и HTTPS через Nginx | Реализовано, нужна проверка на VPS | Проверить свежую установку на Ubuntu, вход через публичный домен и продление сертификата. |
| Наблюдение VPS и Docker-инвентарь | Готово для подготовленных VPS | В карточке видны результаты SSH-проверки, состояния зарегистрированных контейнеров и их порты. |
| Подтверждение и выполнение перезапуска | Готово для тестовой цели | На подготовленном стенде владелец подтверждает перезапуск и видит результат в хронологии. |
| Единая долговечная очередь операций | Следующий этап | Наблюдения и изменения используют общую очередь. После сбоя видно состояние задачи, неизвестный результат требует сверки. |
| Подключение и подготовка чистой VPS | Частично реализовано | Из браузера проверяются отпечаток, доступ и условия, устанавливаются ограниченный сервисный доступ и зависимости. |
| Настройка firewall | Запланировано | Изменения применяются с проверкой нового SSH-соединения и возвратом правил при потере доступа. |
| Remnawave Panel и Node | Запланировано | Panel и Node развёртываются и настраиваются из HostOrbit. Первичная регистрация Node выполняется в Panel. |
| Bedolaga Bot и Cabinet | Запланировано | Работают HTTPS webhook, кабинет и проксирование его API через Nginx. |
| Подключение и удаление существующих установок | Запланировано | Владелец подтверждает известный Compose-профиль, видит внешние изменения и может убрать управляемые компоненты с сохранением данных и общих ресурсов. |

**За рамками первой версии** — резервное копирование и восстановление, перенос старой базы HostOrbit, обновление приложений и расширенный интерфейс аудита.

## Запуск development-сборки

На чистой Ubuntu Server 24.04 или 26.04 amd64:

```sh
git clone https://github.com/RoyMan810/HostOrbit.git
sudo ./HostOrbit/install
```

Установщик выведет локальный HTTPS URL, команду SSH-туннеля и путь к сертификату. Для публичного HTTPS используйте `--public-domain` с готовым сертификатом Certbot.
